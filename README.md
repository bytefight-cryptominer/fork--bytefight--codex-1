# ByteFight Agent

Build a competitive territory-control bot for [ByteFight 2026: Paint](https://bytefight.org/).

## Quickstart

```bash
bash eval/eval.sh          # evaluate baseline agent
cat run.log                # check results
```

## Task

Evolve `agent/controller.py` to maximize Glicko-1 rating against a frozen opponent pool. The baseline is a random mover — there is enormous room for improvement.

See `program.md` for full instructions.
